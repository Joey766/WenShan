# 问山｜产品与交互设定（给 Codex 阅读）

## 核心定位
中文版沉浸式 AI 易经互动网站：国风水墨 + 软萌 3D 角色 + 起卦解卦 + 长期宠物陪伴。不是传统填表式算命工具，不把卦象/AI 说法当成可靠的未来预测。

## 固定 IP
- 小卦：奶白圆团子，竹笠、萌芽、挂铜钱/流苏。
- 云爻：奶白云团子，云纹、金色光环。
- 青朴：淡绿圆团子，叶片伞帽、露滴。
- 玄机：炭黑星点圆团子，金色轨道、太极饰物。
共同表情：极简圆眼、短短略歪的呆萌嘴、圆润糯团体型。形象一致性优先。

## 三幕连贯体验（用户已选 1 / 3 / 5）
1. 山海入口：首页四个角色分散在山海里，鼠标悬停角色可跳跃/挥手，悬停建筑/云/铃铛可产生轻动效；用户选择宠物，点击进入。
2. 问心台：镜头从首页中央迷雾前进，被云雾包围，雾散后到达问心台。用户写下想问的一件事，三枚铜钱合计投掷六次。每次铜钱从石台跃起，摄像机向上跟随，再转俯视捕捉落地；单次结果明确显示 6/7/8/9 和阴阳静动爻，从下往上累计六爻。用户选定的宠物全程陪同。
3. 观卦阁：本卦/动爻/变卦+可靠可核验的《周易》卦辞爻辞+AI 白话解读+继续追问。转场以卦象发光和镜头进入阁楼表现。

## 起卦与 AI 边界
- 程序实现三钱法，每次三枚硬币可得 6、7、8、9；六次自下而上成卦，动爻 6 和 9 翻转形成变卦。结果必须与屏幕可见铜钱一致。
- 独立资料层存储六十四卦及文本来源；不要直接抓取有版权的现代商业解读。
- AI（可先试 Ollama 本地模型）只根据用户问题、已算出的卦、对应古文作解释与继续对话，不编造算卦过程，不保证结果的现实真实性。

## 用户/宠物
- 首次试玩无需注册；用户可选一只宠物和昵称。
- 本地保存宠物选择；登录后可跨设备同步选择、成长和获得用户同意保存的问卦记录。
- 宠物成长和登录活跃状态由程序规则驱动：长期陪伴变活泼/解锁表情；离开几天可以困倦、蔫巴、略微瘦小，但不死亡、不永久惩罚、不制造压力，回来互动能恢复。

## 开发策略
先完成场景概念图及正式素材，再生成包含素材映射、交互、AI 接口、移动端适配、隐私/后端要求的完整 Codex Prompt。不要从单张 PNG 承诺已经拥有完整 3D、分层或 hover 动画。
