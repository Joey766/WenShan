# 《周易》资料与呈现规则

## 经文

以中文维基文库每卦「易經」小节为转录底本，保留繁体、原标点和原字形。64 条卦辞、384 条爻辞和乾坤两条用辞均保留可定位到具体修订的来源链接。导入时去除异体字提示、样式和脚注标号，保留该修订选用的经文字形。古文与本项目撰写的白话、关键词分开维护。 [维基文库《周易》](https://zh.wikisource.org/zh-hans/%E5%91%A8%E6%98%93)

中国哲学书电子化计划的《周易》为参考入口。该站正文页面返回 403，本版未做两个底本的逐字异文校勘。 [中国哲学书电子化计划《周易》](https://ctext.org/book-of-changes)

- [经文 JSON](../src/data/zhouyi.json) 保存卦序、来源、卦辞、六条爻辞、两条特殊用辞。爻辞顺序为初爻至上爻。
- [卦序对照表](../src/data/zhouyi-index.json) 来自维基文库六十四卦速查表。行是下卦，列是上卦。

古代经文另有原始来源。维基文库社区的现代整理、标点等部分若适用社区许可，按 CC BY-SA 4.0 标示。数据逐卦保留修订链接及其历史。本项目的整理操作见上文。 [维基媒体使用条款](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- [编者白话和关键词](../src/data/zhouyi-notes.ts) 是项目自行撰写的 64 条概述，每卦附 3 个关键词。
- [知识库接口](../src/lib/knowledge.ts) 以卦序返回卦名、卦符、上卦、下卦、自下而上的六爻、古文、来源、白话与关键词。
- [导入脚本](../scripts/import-zhouyi.py) 使用 Python 和 BeautifulSoup，从各卦页面抽取经文。安装依赖供重新导入使用。应用运行和构建直接读取随项目提供的本地数据。

## 本版选文方法

先读本卦卦辞，再按从下往上的顺序列出全部动爻的本卦爻辞，并呈现变卦卦辞。六爻皆静时，变卦等于本卦，可以展开全部六条爻辞阅读。乾卦六爻皆动时额外显示用九，坤卦六爻皆动时额外显示用六。这两条附文和各自卦辞、爻辞的出处相同。动爻选文有多种传承，这是「问山」用于阅读和讨论的呈现方法。 [乾卦经文](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E4%B9%BE) · [坤卦经文](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E5%9D%A4)

## 本地模型

服务端按六次铜钱记录重新计算结果，将原问题、补充背景、每次投掷、两卦结构、相关爻辞、经文出处和近期对话传给本机模型。卦象、原文和编者注记直接取自本地知识库。模型可按已确认的卦辞顺序做逐句白话，解释当前动爻，并结合问题组织建议。乾坤采用已撰写的逐句注记，标注为「编者白话」。

观卦阁初始化即可阅览经文和编者释意。服务端传送生成阶段，最终通过结构、词句和数字筛查的内容才进入长卷。生成可取消、重试并沿用原卦。演示模式提供针对问题的参考，沿用程序得到的全部卦象与出处。
