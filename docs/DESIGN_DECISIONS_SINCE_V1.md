# 问山 · v1 素材包之后的设计决定（v2）

## 当前产品定位

- 中文版「问山」：3D 国风山海世界 + AI 易经问卦 + 四个长期陪伴的呆萌宠物。
- **不是**三张互不关联的静态网页。镜头与场景应衔接，用户能看见动画和回应。
- 前期只做三个主要场景：① 山海入口；② 问心台；③ 观卦阁。

## 角色和宠物

- 固定四个定稿 IP：小卦（草帽、铜钱）、云爻（金色云纹、光环）、青朴（浅绿、叶帽、水滴）、玄机（深色星点、金色环轨与阴阳饰物）。
- 鼠标悬停时动作可包括眨眼、歪头、挥手、原地小跳、翘起短脚；选中的宠物贯穿三个场景。
- 四个 IP **始终以 v1 定稿源图外观为准**，不能误把四个都替换成小卦。后续可以为每只补充独立透明立绘/3D模型/动作集。
- 初次体验可不注册，选择可先放浏览器本地；登录后可云端保存永久选择，并跨设备同步。
- 陪伴时间积累可以解锁体型细节、饰品、表情/动作；长期未登录可出现短暂蔫巴、变瘪或饥饿状，但不会死亡或永久掉级，回来互动后可恢复。

## 三幕故事板

1. **山海入口**：用户选宠物，四只小灵物在山峰、水墨荒漠、建筑、云雾环境中。点击「入山问卦」，镜头沿正中的雾道往前推进，云层遮挡完成场景转换。
2. **问心台**：选择的宠物在古老八卦石台旁；用户先写一个具体问题，再投三枚铜钱 **六次**。每次都先有铜钱翻转升空、镜头跟随上升，在最高点转为俯视、落下并停稳；UI 清楚显示当次三钱结果、6/7/8/9爻值、爻名及六爻累计进度。
3. **观卦阁**：第六次结束后，卦象升起并再次通过云雾/建筑进入云上阁楼。古卷打开，左/中区域显示本卦、动爻、变卦、卦辞、爻辞，右侧显示 Ollama 或云端大模型的中文解释，允许继续追问、保存历史。

## 易经逻辑与 AI 边界

- 三枚铜钱法：每枚赋予固定2/3点，三枚和为6、7、8、9；六次**由下往上**形成本卦，老阴6与老阳9是动爻，翻转为变卦。
- 起卦规则、64卦映射、动爻、变卦都应由确定性程序实现和单元测试，不允许大模型临时编造。
- AI 根据用户的问题、真实计算结果、古文资料输出可追溯的白话解读；这是文化娱乐与自我反思，**不是可靠的未来预测**。
- 页面中的卦名和古文不要预先烘焙在背景图里；应由代码动态显示真实结果。正式发布前校对《周易》原文来源和使用权限。

## 视觉与镜头技术

- 已确定首页：柔和、立体、3D 软萌感，远山、瀑布、云海、建筑、朱砂落日，四IP分区可交互。
- 第二幕候选图存在较多金色 UI 光效，后续正式开发可以适度简化，突出阅读清晰度。
- 场景切换可采用 2.5D 多层视差 + 云雾过渡；铜钱翻转与运动镜头建议用真实 3D 对象/动画。
- 角色要优先制作不带背景的独立动作，而不能让整个背景跟着角色一起跳。

## 技术/开发准备

- Next.js + 动画库 + Three.js/R3F 用于网页和3D铜钱；Ollama 用于本地原型 AI 解读；线上需独立模型服务或云端API。
- 后续给 Codex 的正式 Prompt：一次性写清三幕结构、交互事件、素材路径、镜头曲线、投币规则、数据模型、账户存档、宠物成长、AI解释、安全与性能降级。
- 先整理与验证素材，用户目前**不要求直接开发最终网站**。
