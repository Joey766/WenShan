
# 问山第三轮 AI 占卜

## 一问一卦

出卦后直接显示判断、卦象依据和一句大白话。默认流程没有补充背景和主动追问。复用原有六轮铜钱和周易知识库，保留已存旧记录。「经文与白话」可查看原辞、爻辞、编者释意和对应来源。乾坤已有编者逐句注释，其他卦可在经文页主动请求本机模型按句释读。

## 倾向判定

`src/lib/interpretation.ts` 将真实本卦卦辞、动爻及变卦卦辞的吉、凶、厉、不利等信号按固定规则读取。有变时重点看动爻，乾坤全动按用九、用六；静卦读本卦。信号混合可得中平或偏慎。规则是本站用于保持一致的文化解读约定，不能替代对各爻和异文的细读。

`src/lib/question-context.ts` 将同一倾向自然表达为球运、考运、工作、感情音讯、财运或日常运势。问题类别、生日及性别均不改变算出的卦或倾向。同一问题换一卦，依据和倾向会随实际卦象改变。

## 协议与等待

- `src/app/api/reading/route.ts` 返回 `verdict`、`directAnswer`、`hexagramBasis`、`closing` 四项结果字段。第一句由程序立即推送，无需加载 Ollama。
- `src/lib/reading-generation.ts` 将实际资料交给本机 Ollama。模型写一句取象白话，并从符合问题和已定倾向的限定句中择取收尾。程序核对关联词、倾向和内容边界，无法采用的白话使用内置释意。模型不可用、流中断或两节都不可用时显示演示模式。
- 模型与页面都用流式通道。收到一个完整小节就推送，本卦名、动爻、变卦与其经文仍由程序呈现。界面固定标明「传统文化娱乐体验，非现实预测」。
- 默认 `qwen3:4b`，可用 `OLLAMA_MODEL` 更换为已安装的本地模型。主答上下文 2048，生成最多 240 token，关闭深思，保留 6 分钟。整次请求上限 116 秒，模型探测上限 1.6 秒。
- 页脚每秒更新粗略剩余时间。当前浏览器只保留最近五次完整本地耗时，无历史时以 22 秒为初始参考，超时则显示「比预计久」。样本不附带题目、生日或回答。

用 `npm.cmd run test:ollama` 复跑六种固定卦例。测试覆盖用户要求的五个问题，以及用不同卦象重复同一个足球问题。
