## Codex 的正确使用方式

1. 扫描此素材包、阅读 `docs/PRODUCT_BRIEF.md`，建立素材地图。
2. 所有页面、模型和 UI 以已确认的角色 PNG 为形象来源；禁止用最初的黄色表情参考图替换任何正式角色。
3. 暂时只用现有素材做视觉验证；要实现真正的角色鼠标悬停跳跃/挥手，后续需补独立透明动画素材或结构化 2D/3D 角色。
4. 首页穿云的镜头推进，可先规划 2.5D 多层背景、视差与雾幕遮挡的方案，最终根据未来补齐的资产制作；不要声称单张 PNG 已可进行真实空间穿越。
5. 第二幕抛铜钱的真实三维运动与俯视镜头，应使用独立 3D 铜钱、摄像机轨道和规则引擎；AI 不负责随机决定卦象。
6. 现阶段**不要在未经要求时自动生成完整网页**：先保留项目架构、素材清单，等用户逐场景确认后再实现。
