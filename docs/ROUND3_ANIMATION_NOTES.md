# 问山第三轮灵宠动画

## 待机和动作

`src/components/pet-art.tsx` 复用四只角色原有的透明头饰、眼睛、手与身体素材。`src/components/pet-motion.ts` 用 Web Animations API 分开漂浮重心、身体呼吸、眼神与表情、上层事件动作。漂浮和呼吸速度相互错开，眼神有自己的计时与幅度，抛掷事件覆盖视线时仍保留身体待机。

| 灵宠 | 呼吸周期约 | 待机个性 |
|---|---:|---|
| 小卦 | 4.5 秒 | 先昂头停一下，再好奇探身，挠头两拍较紧凑 |
| 云爻 | 5.8 秒 | 沿轻慢的弧线横漂，回落时云团缓缓舒展，挠头第二拍停得更久 |
| 青朴 | 5.2 秒 | 盘稳重心后轻弹，落地有压缩回弹，双挠较轻 |
| 玄机 | 4.8 秒 | 眼睛先扫向一侧，再转向另一侧，身体较晚跟上，抬手前多停一拍 |

挠头的参考节奏取自用户提供的小黄视频及此前逐帧检查。先短暂停住，再歪头，抬手做两次轻挠，手臂连着身体回落，身体轻轻回弹。每只角色有不同的起势、手臂角度、双挠节拍和自动动作分布。首轮挠头错开，随后有随机冷却。同屏有灵宠正在挠头时，其他灵宠自动候一会儿。这些安排在持续呼吸层上叠加，起始姿势取当时的实时变换。

点击触发各自的打招呼动作。铜钱飞起时抬眼跟随，落地有轻弹。等待解读时先思考，之后仍穿插微动作。答案就绪时看向卷轴再庆祝。页面隐藏时暂停已启动的动画，系统或站点的减少动画设置会停用角色运动。

现有 GIF、分镜及美术原稿均可继续用作参考。运行时显示原定稿分层图和程序插值。测试在本机桌面浏览器和模拟手机视口进行，实体手机的帧节奏仍需另测。
