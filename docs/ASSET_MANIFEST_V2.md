# 问山 · v2 增量素材清单

> **使用方法**：必须先有 v1 素材包；将本 ZIP **解压到同一个 `塔罗project/` 根目录**。不要删除/覆盖 v1 的四角色定稿源图。

## 本包内容

- 第二幕「问心台」4 张 3D 场景/UI 候选图。
- 第三幕「观卦阁」1 张 3D 结果解读候选图。
- 小卦4组跳跃/翘脚动态分镜参考。
- 云爻3组3D角色探索、1份浮动GIF和关键帧参考。
- 青朴：跳跃GIF、透明GIF、透明PNG。
- 玄机：9格跳跃分镜、独立可播放的循环GIF。
- 云爻临时裁剪实验2张，仅供追溯，不建议在正式网站调用。

## 版本状态（非常重要）

- **正式角色身份和基本外观以 v1 `assets/reference/characters_4_approved.png` 为唯一准则。** v2 中动作探索可能增加星星、手脚或装饰，不能覆盖角色身份。
- 第二幕已被用户认可为 3D 暖色国风风格，后续从候选图中择优做成真正可拆分、可交互的场景。
- 第三幕仅有解读页概念图；图上的六爻图示/文字是占位示例，**并非正确的实时易经计算结果**。
- 所有**带背景的 GIF/分镜**属于概念验证素材，不是可直接自由移动的 3D 角色模型。
- v2 是 **增量包**，并不重复分发 v1 已包含的首页图或四角色定稿图。
