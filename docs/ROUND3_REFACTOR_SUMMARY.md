# 问山第三轮整改

## 本轮改动

- 三幕沿用原有美术和镜头路径。慢速画面呼吸、柔光和摇摆的铃铛增加纵深，远雾、近雾、灯笼、水纹及粒子保持原有层次。阅读区留出整列文字空间，来源与结果仍能独立查看。相关文件是 `world.tsx`、`world.css` 和 `entrance.tsx`。
- 四灵宠通过持续底层呼吸轻浮、独立视线及事件层混合动作。点击与抛币不重新启动底层。参见 [动画说明](ROUND3_ANIMATION_NOTES.md)。
- 首访先弹生日和性别，可跳过、编辑或清除。资料存于浏览器，授权后只让本机模型使用年龄段和性别选项。三枚铜钱各自独立随机。相关文件是 `profile.tsx`、`profile.ts`。
- 按最新定位收口为一问一卦。直接判断、卦象依据和一句大白话按节展示。问心台只有问题框，观卦阁保留经文与白话、返回再问、可选保存。参见 [AI 说明](ROUND3_AI_NOTES.md)。

## 验证

回归覆盖固定卦例与不同倾向、同题换卦、分片解码、提前显示判断、持续待机和三幕流程。

构建、TypeScript 和 15 项单元测试通过。真实本机 `qwen3:4b` 六例通过，首句经本机 API 到达用时 6–46 ms，完整回答 6.79–10.64 秒。六例的首句及依据可复核到实际卦象，模型从对应备选句中选出收尾。试跑中的自由白话均未通过校验，采用了内置释意，并在界面标明。

一问一答正式流程在 Edge 桌面 1440 × 900 和模拟手机 390 × 844 上通过 13 项，覆盖全屏三幕、真实六轮铜钱、资料与本地存档、模型不可用、流式进度和取消重试。设备为本机桌面与手机视口模拟。

加入四套同屏个性动作后，桌面和模拟手机的点击、看铜钱、落地与回到待机检查通过。桌面另一次连续采样观察到四只分别做出探身、缓漂、轻弹和扫视，随后各自错峰挠头。验收同时抽查了坎卦，已将「维心亨」按险中持稳判读。
